# The James Webb Space Telescope

`jwst.bin` is derived from **"The James Webb Space Telescope"** by **Ignazio Pillitteri** (@gnaz),
<https://sketchfab.com/3d-models/the-james-webb-space-telescope-dcb95b3193be49e7a60192055df2315d>,
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Changes: generated by `bun scripts/build-jwst.ts` from the model's glTF export (`scene.gltf` + `scene.bin`, downloaded from
the page above — **not in the repository**, ignored by git): the scene hierarchy flattened, the mesh scaled to metres and
re-oriented (the sunshield towards −Y), each vertex given a surface kind (structure, gold mirror, Kapton foil, solar array)
and an sRGB colour; the model's textures are not used (the app shades the craft procedurally, `src/shaders/jwst.wgsl`).
This derived file is distributed under the same licence.

To rebuild: download the model as glTF from Sketchfab, put `scene.gltf` and `scene.bin` here, run `bun scripts/build-jwst.ts`.
