# Real-sky data

Generated by `bun scripts/build-sky.ts <dir>` from:

| File | Source | Licence / credit |
|---|---|---|
| `milkyway.webp` | NASA/Goddard Space Flight Center Scientific Visualization Studio, *Deep Star Maps 2020* — `milkyway_2020_8k.exr` (Milky Way background without the Hipparcos/Tycho stars, celestial coordinates), <https://svs.gsfc.nasa.gov/4851> | NASA/Goddard SVS. Gaia DR2: ESA/Gaia/DPAC |
| `stars.bin`, `starlod.bin` | HYG star database v4.4 (Hipparcos, Yale Bright Star, Gliese), <https://codeberg.org/astronexus/hyg> | CC BY-SA 4.0, © David Nash / astronexus — these derived files are distributed under the same licence |

Formats (all little-endian):

- `milkyway.webp`: 4096×2048 equirectangular, u = 0.5 − RA/360°, v = (90° − Dec)/180°. Log-encoded
  8-bit channels: value = 2^(16·c − 16), c = byte/255 (0 = black). Decoded to linear half floats
  with mips on the GPU (`src/shaders/sky.wgsl`).
- `stars.bin` (gzip): `u32 magic "STR1", grid, count, 0`, `u32 cellStart[6·grid²+1]` (cube-map cells,
  same face/axis convention as `faceUV` in `trace.wgsl`), then per star `f32 x, y, z` (ICRS unit
  vector) and `u32` = f16 V magnitude | f16 temperature/1000 K (Ballesteros 2012 from B−V).
- `starlod.bin` (gzip): `u32 magic "SKY1", width, height, levels`, then rgb9e5 texels of every mip
  level: the catalogue's radiance, used where a pixel's lensed footprint covers many stars.

Photometric scale: map value 0.1 ≈ 20 mag/arcsec² (V); a star of magnitude m has flux
10^(−0.4 m)/4250 in map-value·sr units.
