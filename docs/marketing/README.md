# KERR — images marketing

Toutes faites par le jeu lui-même, en temps réel (pipeline raster), sur un MacBook Pro M1 Max, 1920 × 1080 :
`bun scripts/showcase-shots.ts`, puis `python3 scripts/build-showcase.py` (29/10/2026).

- **Affiches** (`poster-*.jpg`) : l'emblème, KERR, une ligne en français et en anglais.
- **Vues** : les F-35 en formation (Mont-Blanc, Corse, Provence, détroit de Gibraltar, Himalaya, Patagonie, fjords,
  Islande, Grand Canyon), l'A320 (au-dessus des nuages, Paris au crépuscule, les Alpes, sur la piste), rayons crépusculaires,
  arc-en-ciel, orage, reflet du soleil sur la mer ; la Lune, Saturne, Gargantua.
- **Planche contact** (`contact-sheet.jpg`) : toutes les prises, météos et heures comprises (celles-ci dans
  `assets/title/`).
