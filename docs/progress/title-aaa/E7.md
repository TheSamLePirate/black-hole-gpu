## Plus…

« Plus… » n'est plus une liste à plat. Les entrées sont rangées en six groupes, avec la même liste et le même
aperçu que les écrans de mode :

| groupe | entrées |
|---|---|
| **Jouer** | Toutes les scènes (la galerie), Charger une partie |
| **Créer** | Mode photo et rendus, Éditeur de missions |
| **Ensemble** | Jouer ensemble (quand le réseau est montré) |
| **Apprendre** | Comment jouer et Découvrir (les pages `docs/comment-jouer.html` et `docs/decouvrir.html`, dans un nouvel onglet), Commandes |
| **Mesurer** | Kerr Bench, **confirmé d'abord** : un écran dit que la page va se recharger pour mesurer cette machine, et que la partie en cours est sauvegardée. « Lancer la mesure » a le focus ; « Annuler » ou Échap ramènent à Plus… |
| **Le jeu** | Crédits, puis la **langue**, sur une ligne ◂ Français ▸ : la changer recharge la page dans l'autre langue |

## Les Crédits

Un **générique déroulant**, centré sur fond noir :

- il s'ouvre sur l'emblème du jeu, KERR et sa ligne ;
- puis « Un jeu de SamLePirate » ;
- puis, section par section :
  - les vaisseaux et les modèles ;
  - le ciel ;
  - les mondes ;
  - les cartes, la météo et le trafic ;
  - les photographies des paysages ;
  - les logiciels et les polices ;
  - l'hommage à Interstellar ;
- il se ferme sur l'emblème et « Merci d'avoir joué ».

Chaque entrée donne l'œuvre, puis en grand ses auteurs, puis en petit sa licence.

**Le défilement.** Le générique monte seul (~38 px/s). ↑ ↓, Page ↑/↓, Espace, la molette ou un glisser en
prennent la main ; il repart seul 3 s plus tard. Échap ou B le passent. Avec le mouvement réduit, il ne défile
pas seul.

**Une source unique.** `src/ui/title/credits.ts` alimente à la fois l'écran et `CREDITS.md`, que génère
`bun scripts/build-credits.ts`. Les photographes viennent des données des paysages (`LANDSCAPES`) : le
générique les suit quand un paysage est ajouté. `tests/title-credits.test.ts` vérifie :

- chaque entrée tirée du README d'un asset : son auteur et sa licence figurent dans ce README ;
- `CREDITS.md` : c'est bien celui qu'écrit le script, sans retouche à la main.

**À compléter.** Les porte-avions (Gerald R. Ford, Kiev, Implacable), les avions de ligne et les navires du
trafic viennent de modèles fournis (`assets/porte-avion/`) sans README. Leurs auteurs ne sont donc pas encore
nommés : l'entrée dit « Modèles 3D fournis, sous la licence de leurs auteurs ». Ajouter un README par modèle
permettra de les créditer comme les autres.
